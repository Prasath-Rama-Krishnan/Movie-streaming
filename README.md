# 🎬 Movie Streaming Website

A full-stack **Movie Streaming Web Application** built using modern web technologies.  
This project enables users to **register/login using OTP**, **browse/search movies**, **view movie details**, **stream video content**, and **manage a watchlist**, all with a responsive and interactive UI.



---

## 🧠 Project Overview

This platform simulates a real-world movie streaming service where users can:

- Register/login securely via **OTP authentication**
- Explore featured movies and categories
- Search movies by name or filter by genre
- View movie details (poster, description, rating)
- Stream video content from cloud storage
- Add movies to a personalized **watchlist**

The system is built as a **Single Page Application (SPA)** with a Node.js backend and cloud-based media streaming.
